# Plan Command

Crea un plan de implementación detallado para: $ARGUMENTS

## Tu Tarea

1. **Restaurar Requisitos** — Clarificar qué se necesita construir
2. **Identificar Riesgos** — Superficie de posibles problemas y dependencias
3. **Crear Plan por Fases** — Desglosar en pasos con archivos específicos
4. **Esperar Confirmación** — NO escribir código hasta que el usuario apruebe

## Formato

### Requisitos
[Resumen claro de lo que se construirá]

### Fases de Implementación
[Paso 1: Descripción] (Archivo: ruta)
[Paso 2: Descripción] (Archivo: ruta)

### Dependencias
[APIs, servicios, librerías necesarias]

### Riesgos
- HIGH: [Riesgos críticos]
- MEDIUM: [Riesgos moderados]
- LOW: [Preocupaciones menores]

**ESPERANDO CONFIRMACIÓN**: ¿Proceder con este plan? (sí/no/modificar)
