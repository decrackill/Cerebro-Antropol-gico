# Discovery Approve Command

```markdown
### Tickets a Crear
1. **[Ticket 1]**: [descripción]
2. **[Ticket 2]**: [descripción]

### Prioridades
- Crítica: [ticket]
- Alta: [ticket]
- Media: [ticket]

### Notas
[observaciones adicionales]
```
