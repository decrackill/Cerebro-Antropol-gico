# Learn Command

Extraer patrones y aprendizajes de la sesión actual: $ARGUMENTS

## Tu Tarea

1. Revisar la conversación de la sesión actual
2. Identificar patrones, decisiones y aprendizajes
3. Documentar en un formato estructurado

```markdown
- [decisión]: [razón]

### Patrones Identificados
- [patrón]: [descripción]

### Problemas y Soluciones
- [problema]: [solución]

### Próximos Pasos
- [acción pendiente]
```
