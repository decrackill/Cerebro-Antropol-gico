# Orchestrate Command

Orquestar múltiples agentes para: $ARGUMENTS

## Tu Tarea

1. Desglosar la tarea en subtareas independientes
2. Asignar cada subtarea al agente especializado
3. Coordinar la ejecución paralela
4. Consolidar resultados

## Agentes Disponibles

| Agente | Especialidad |
|--------|-------------|
| planner | Planificación |
| architect | Arquitectura |
| code-reviewer | Code review |
| security-reviewer | Seguridad |
| tdd-guide | TDD |
| build-error-resolver | Errores de build |
| e2e-runner | E2E tests |
| refactor-cleaner | Limpieza |
| doc-updater | Documentación |

## Formato del Plan de Orquestación

### Subtarea 1: [nombre] → agente: [agente]
- [Instrucciones específicas]

### Subtarea 2: [nombre] → agente: [agente]
- [Instrucciones específicas]

### Dependencias
- Subtarea 2 depende de Subtarea 1
- Subtarea 3 es independiente

### Consolidación
- Cómo integrar los resultados
- Verificación final
