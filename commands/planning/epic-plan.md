# Epic Plan Command

Generar planificación de epic: $ARGUMENTS

## Formato

```markdown
## Epic Plan: [nombre]

### Alcance
[qué incluye y qué no]

### Fases
#### Fase 1: [nombre]
- Objetivo:
- Tickets:
- Dependencias:
- Riesgos:

#### Fase 2: [nombre]
...

### Timeline Estimado
- Fase 1: [tiempo]
- Fase 2: [tiempo]

### Riesgos Globales
- [Riesgo]: [mitigación]
```
