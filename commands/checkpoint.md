# Checkpoint Command

Guardar estado de verificación y progreso: $ARGUMENTS

## Tu Tarea

1. Verificar estado actual de los archivos modificados
2. Ejecutar tests rápidos
3. Guardar resumen del progreso

## Formato

```markdown
## Checkpoint — [timestamp]

### Estado
- Tests: [pass/fail count]
- Archivos modificados: [lista]
- Cambios sin commit: [sí/no]

### Progreso
- [ ] Tarea 1 — COMPLETADA
- [ ] Tarea 2 — EN PROGRESO
- [ ] Tarea 3 — PENDIENTE

### Notas
[observaciones, bloqueos, decisiones]
```
